Help & Getting Started

Platform Overview

Kiboko Project Prioritization Manager (PPM) helps your team plan, prioritize, and track ecommerce projects against revenue goals. The platform connects strategic Annual Rocks to actionable Quarterly Rocks and individual Projects, then measures their impact on revenue through budget goals, daily actuals, and forecasts.

Key areas of the application:

  • Dashboard — Month-to-date, quarter-to-date, and year-to-date revenue charts comparing actuals, forecasts, and budget targets.
  • Kanban — A drag-and-drop board for tracking active projects across lanes (Blocked, Incomplete Entry, Ready to Score, Scored, On Deck, Active) with KPI rollups per lane.
  • Projects — Submit, score, estimate, and approve projects. Each project is linked to a Quarterly Rock and can contribute projected revenue uplift to your forecast.
  • Revenue — Set monthly budget goals per vertical and upload daily actual revenue from CSV files.
  • Admin — Configure company structure (departments, verticals), rocks, measurements, and users.

Theme: Use the sun/moon icon at the bottom of the left sidebar to switch between dark and light modes. Your preference is remembered across sessions.

Workflow: Initial Setup

Complete these steps before adding projects or tracking revenue.

  1. Create Departments — Go to Admin → Company and add each department (e.g., Marketing, Merchandising). Assign a department owner.
  2. Create Verticals — On the same Company page, add your revenue verticals (e.g., Lighting, Furniture). Assign a General Manager to each.
  3. Add Annual Rocks — Go to Admin → Rocks and create the Annual Rocks for the current year. These represent your top strategic priorities.
  4. Add Quarterly Rocks — Still on the Rocks page, create Quarterly Rocks linked to an Annual Rock. Assign a department, year, and quarter.
  5. Configure Measurements — Go to Admin → Measurements to define the Metrics and KPIs used when scoring projects.
  6. Add Users — Go to Admin → Users to create accounts and assign roles (admin, senior_leadership, department_owner, or staff).
  7. Set Budget Goals — Go to Revenue → Edit Goals, select a vertical, and enter monthly budget targets for the year.

Workflow: Add a Project

  1. Navigate to Add Project — In the left sidebar click Add Project → New Project.
  2. Fill in Project Details — Enter the project name, select the linked Quarterly Rock, department, vertical, and provide a description. Set the estimated annual revenue value and planned launch date.
  3. Submit for Scoring — Once submitted, the project enters the scoring pipeline where leadership can estimate value and level of effort (LOE).
  4. Estimate Value & LOE — Authorized users go to Estimate Value & LOE to score projects. Value estimates are set by senior leadership; LOE estimates can be provided by department owners.
  5. Approve — Go to Estimate Value & LOE → Approve Projects to approve or reject scored projects. Approved projects become Active and appear on the Dashboard.
  6. Track on Dashboard — Active projects contribute a projected revenue uplift to the forecast charts, based on their estimated value and launch date.

Workflow: Updating Actuals

  1. Prepare your CSV — Create a CSV file with two columns: Date and Actual Revenue. Supported date formats include YYYY-MM-DD, MM/DD/YYYY, and MM/DD/YY.
  2. Go to Update Actuals — In the left sidebar click Revenue → Update Actuals.
  3. Select a Vertical — Choose the vertical this revenue data belongs to from the dropdown.
  4. Upload the File — Select your CSV file and click Upload. The system will create or update daily revenue records. Any parsing errors are reported after upload.
  5. Verify on Dashboard — Return to the Dashboard to see updated actuals reflected in the MTD, QTD, and YTD charts. The forecast automatically adjusts based on new actual data.

Tip: Re-uploading a date for the same vertical will overwrite the previous value, so you can correct mistakes by uploading a corrected CSV.
